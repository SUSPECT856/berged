# Berged 0.9

## Start

```bash
npm start
```

Then open the preview at the port shown by your environment (default: 3000).

### What is included
- Responsive Berged chat UI
- Normal theme: Sistem / Beyaz / Koyu
- Chat themes: Sade / Kalpler / Köpek / Kurbağa / Kedi / Çiçekler / Dino / Okyanus
- Font style changes ONLY the user's sent messages
- Bubble styles with decorative elements
- Bottom-sheet customization panel
- LocalStorage persistence
- No external AI API and no third-party runtime dependencies
